## 3.9 Hands-On Exploration Tasks

**Task A: `app/Models/User.php`, the `$fillable` property**
`$fillable` lists the columns that may be mass-assigned, meaning set all at once through `User::create([...])` or `$user->update([...])`. It matters because it protects against *mass-assignment vulnerabilities*. Without it, a user could add extra fields to a form (for example `is_admin=1`) and Laravel would write them to the database. Only the listed columns (`name`, `email`, `password`) are accepted. Every other column is ignored.
*(Note: newer Laravel versions declare this with the attribute `#[Fillable(['name', 'email', 'password'])]` above the class. It does the same job as `protected $fillable = [...]`.)*

**Task D: `resources/views/welcome.blade.php`**
A full HTML5 document: `<!DOCTYPE html>`, then `<html>` with a `<head>` (meta charset, viewport, `<title>` from `config('app.name')`, fonts, and the Vite or inline styles), then a `<body>` containing a header/nav area (login/register links when those routes exist), the main content section with the Laravel logo and the documentation/Laracasts links, and closing tags. It uses Blade syntax such as `{{ }}` and `@if (Route::has('login'))`.

**Task E: `.env`, `DB_DATABASE`**
With MySQL selected in the installer, `DB_DATABASE` holds the project's database name (here `workshop_week1`). On a default SQLite install, the line is commented out and the database is the file `database/database.sqlite`.

**Task F: why never edit files in `vendor/`?**
`vendor/` is generated by Composer from `composer.json` and `composer.lock`. Any edit is lost the next time someone runs `composer install` or `composer update`. The folder is also listed in `.gitignore`, so your changes would never reach Git or your teammates. Customise behaviour in your own code instead (extend classes, use service providers, publish config).

## 6.4 Debug functions
`dd()` dumps and stops. `dump()` dumps and continues. `ddd()` dumps and stops, showing a stack trace page. `logger()` writes to `storage/logs/laravel.log` without stopping.
